| 5 | **The private path** | Node, then edge router or FCR, then Equinix Fabric (redundant VCs), then ExpressRoute private peering, then the ER gateway, then the egress proxy, then the Arc gateway | "No internet egress in the cage. Arc agents use a passthrough proxy that's reachable only over ExpressRoute, and they talk to just nine Arc gateway endpoints." |
| 6 | **Equinix Fabric + ExpressRoute as code** | `azurerm_express_route_circuit` (provider Equinix, Silicon Valley, 50 Mbps). `equinix_fabric_connection` (service key, PRIVATE, C-tag 200).
